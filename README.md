## Можливості

- Паспортні криві потужності всіх чотирьох моделей Dragon (19 точок RPM→W, підтверджено виробником)
- Номінальна потужність при **v = 10 м/с**, гальмування контролера при 11 м/с
- Визначення середньої швидкості вітру **прямо з карти** (ERA5 reanalysis 2015–2024, Open-Meteo API)
- Фізична модель wake-ефекту Jensen + поправка на турбулентність Frandsen (2006)
- Ефект blockage при поперечному вітрі + роза вітрів Von Mises
- 20-річна фінансова модель: NPV, DPP, ROI, деградація обладнання
- Три сценарії: консервативний / базовий / оптимістичний
- Інтерактивний графік оптимальної відстані між турбінами
- Вкладка «Модель» з анімованими SVG-схемами для пояснення фізики клієнту
- Працює офлайн (крім функції карти), не потребує встановлення — один HTML-файл

## Фізичні моделі

- **Jensen (1983)** — wake-слід з лінійним розширенням конуса
- **Frandsen (2006)** — вплив турбулентності на розсіювання wake: `kw_eff = kw + 0.5 × TI`
- **Von Mises** — статистична модель рози вітрів з параметром концентрації κ
- **Weibull** — розподіл швидкостей вітру для розрахунку середньорічної генерації
- **Dabiri (Caltech, 2011)** — blockage-ефект для VAWT ферм
- **ERA5 reanalysis** — кліматологічні дані вітру (Open-Meteo API, 2015–2024)

Точність моделі: ±20–30% (pre-feasibility). Для проєктних рішень рекомендується анемометрування майданчика.
