- Паспортні криві потужності всіх чотирьох моделей Dragon (19 точок RPM→W, підтверджено виробником)

- Фізична модель wake-ефекту Jensen + поправка на турбулентність Frandsen (2006)

- 20-річна фінансова модель: NPV, DPP, ROI, деградація обладнання
- Три сценарії: консервативний / базовий / оптимістичний
- Інтерактивний графік оптимальної відстані між турбінами
- Вкладка «Модель» з анімованими SVG-схемами для пояснення фізики клієнту
- Працює офлайн (крім функції карти) — один HTML-файл без залежностей

## Фізичні моделі

- **Jensen (1983)** — wake-слід з лінійним розширенням конуса
- **Frandsen (2006)** — вплив турбулентності: `kw_eff = kw + 0.5 × TI`
- **Von Mises** — статистична модель рози вітрів з параметром κ
- **Weibull** — розподіл швидкостей вітру для річної генерації
- **Dabiri (Caltech, 2011)** — blockage-ефект для VAWT ферм
- **ERA5 reanalysis** — кліматологічні дані вітру (Open-Meteo API, 2015–2024)

Точність: ±20–30% (pre-feasibility). Для проєктних рішень рекомендується анемометрування.
